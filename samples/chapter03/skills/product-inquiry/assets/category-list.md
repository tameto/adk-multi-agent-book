# 商品カテゴリ一覧

| カテゴリID | 表示名 | 主な商品 |
|---|---|---|
| 周辺機器 | PCサプライ・周辺機器 | マウス、キーボード、USBハブ、ウェブカメラ |
| オーディオ | オーディオ機器 | ヘッドフォン、スピーカー、マイク |
| モニター | ディスプレイ | 4Kモニター、ウルトラワイド |
| ストレージ | 記憶装置 | SSD、HDD、USBメモリ |
| ネットワーク | ネットワーク機器 | ルーター、Wi-Fi中継機 |

## フィルタの使い方

`search_products` の `category` 引数には、上記の「カテゴリID」列の値をそのまま指定します。

```python
search_products(query="マウス", category="周辺機器")
```

`category` を省略すると全カテゴリから検索します。
