# 商品レビュー分析スキル

## 目的
商品レビューデータを分析し、顧客の声から有用なインサイトを抽出する。

## 対応範囲
- 個別商品のレビュー要約
- 感情分析（ポジティブ/ネガティブ/ニュートラル）
- レビュートレンドの可視化

## 分析手順
1. `analyze_reviews` ツールで商品レビューの概要を取得する
2. 感情スコアが 0.3 未満の場合、ネガティブな声が多いことを伝える
3. `get_review_trends` ツールでトレンドデータを確認する
4. 改善ポイントを箇条書きで提案する
5. 出力ルールは `references/output-format.md` を参照

## 注意事項
- レビュー件数が10件未満の場合は「サンプル数が少ない」旨を付記する
- 感情スコアは小数第2位まで表示する
